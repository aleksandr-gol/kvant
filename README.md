# Квант

ИИ-агент для частного инвестора на российском рынке. Пользователь пишет обычным языком — «разбери мой портфель», «хочу накопить 5 млн за 10 лет», «сравни Сбер и ВТБ», «купи 10 акций Газпрома» — агент сам планирует шаги, берёт данные Мосбиржи, Банка России и отчётность МСФО, считает и сверяет каждое число в ответе с данными.

> Ответы агента — аналитика, а не индивидуальная инвестиционная рекомендация. Сделки агент не совершает: он готовит черновик заявки, подтверждает её человек у брокера. Котировки MOEX ISS без подписки идут с задержкой около 15 минут.

## Что умеет

| Задача | Как решается |
|---|---|
| Разбор портфеля | Оценка по рынку, доли, сектора, концентрация, доходность, волатильность, просадка и бета к IMOEX за год, денежный поток (дивиденды и купоны) против ключевой ставки, предупреждения, черновики заявок на ребалансировку |
| План накоплений | 2000 сценариев: облигационная часть — доходность ОФЗ на срок цели по кривой Мосбиржи, акции — история индекса полной доходности MCFTR; налог 13%, вычет ИИС-3, инфляция ЦБ; вероятность цели и нужный взнос для трёх профилей риска |
| Анализ компании | Отчётность МСФО за годы и кварталы, мультипликаторы, дивиденды и отсечки, DCF в рублях (ОФЗ 10 лет вместо американских 4%), для банков — P/BV через ROE |
| Облигации | ОФЗ и корпоративные с фильтрами по сроку и доходности, график купонов, лестница ОФЗ под сумму и срок |
| Рынок | Котировки акций, фондов, облигаций, индексов и юаня; скринер по P/E, P/B, EV/EBITDA, дивдоходности; ключевая ставка, инфляция, курсы ЦБ, кривая ОФЗ; новости РБК, Интерфакса, ЦБ и Мосбиржи |
| Сделка | `draft_order`: лоты, сумма, комиссия, ссылка на бумагу в Т-Инвестициях. Не исполняет |

## Источники данных

Все публичные, ключи не нужны.

| Источник | Что берём |
|---|---|
| [MOEX ISS](https://iss.moex.com/iss/reference/) | поиск бумаг, котировки, свечи, облигации и купоны, кривая бескупонной доходности ОФЗ, индексы, новости биржи |
| [Банк России](https://www.cbr.ru) | ключевая ставка, инфляция и цель, официальные курсы |
| [smart-lab.ru](https://smart-lab.ru) | отчётность МСФО компаний, дивиденды и даты отсечки, таблица мультипликаторов рынка (кэш 6 часов) |
| RSS РБК, Интерфакса, ЦБ | заголовки и анонсы новостей |

## Самопроверка

- **Сверка чисел.** После ответа все числа из текста ищутся в результатах инструментов с учётом округления и единиц («6,3 трлн» ↔ 6 325 839 241 920). На сайте видно «Все N чисел найдены в данных» или список расчётных и непроверенных чисел.
- **Детерминированные расчёты.** Портфель, накопления и заявка считаются кодом, а не моделью; модель их объясняет.
- **Оценка на русских вопросах.** `bun run eval:ru` прогоняет 12 вопросов: выбор инструментов, наличие эталонного числа (берётся из живых данных в момент прогона), доля чисел ответа, найденных в данных, время, токены. Отчёты — в `docs/eval/`.
  Последний прогон на GigaChat-3-Pro (11.11.2026): инструменты выбраны верно в 12 из 12 вопросов, эталонные числа — 4 из 4, обязательное содержание — 6 из 6 (включая сравнение четырёх банков с заявками в одном вопросе), 95% чисел ответов найдены в данных, в среднем 4,4 секунды на вопрос. Отчёт: [docs/eval/eval-GigaChat-3-Pro-2026-11-11-10-56.md](docs/eval/eval-GigaChat-3-Pro-2026-11-11-10-56.md).
- **Тесты.** 358 тестов: разбор всех источников на фикстурах, математика портфеля и накоплений, адаптер GigaChat, сверка чисел, защита от запросов во внутреннюю сеть.

## Запуск

Нужен [Bun](https://bun.sh) 1.3+.

```bash
bun install
cp env.example .env   # вписать GIGACHAT_CREDENTIALS
bun run web           # сайт на http://127.0.0.1:8787
bun start             # терминальная версия
```

Проверки:

```bash
bun run typecheck && bun test
bun run smoke:tools                 # все инструменты на живых данных, без модели
bun run eval:ru --model GigaChat-3-Pro
bun run scripts/ui-check.ts http://127.0.0.1:8787 /tmp   # скриншоты сайта и ошибки консоли
```

Без ключа GigaChat агент работает с любой поддерживаемой моделью: `WEB_MODEL=ollama:qwen3.5:4b bun run web`.

### Docker

```bash
cp env.example .env && $EDITOR .env
docker compose up -d --build        # http://127.0.0.1:18300
```

## Устройство

```
вопрос ─► Agent (цикл агента, до 20 шагов; последний — ответ без инструментов)
            │  системный промпт на русском + SOUL.md + навыки
            ▼
        ChatGigaChat (src/model/gigachat.ts)
            │  вызов функций, по одному за ход
            ▼
        инструменты src/tools/ru/ ──► MOEX ISS · ЦБ · smart-lab · RSS
            │  результат + ссылки на источники
            ▼
        ответ ─► сверка чисел (src/agent/number-check.ts) ─► сайт (SSE)
```

| Каталог | Что внутри |
|---|---|
| `src/model/gigachat.ts` | адаптер GigaChat для LangChain (адрес `api.giga.chat` — только там есть GigaChat-3): OAuth с кэшем токена, функции, потоковый вывод, очистка JSON-схем, очередь запросов под лимиты Freemium |
| `src/tools/ru/` | клиенты MOEX ISS, ЦБ, smart-lab, RSS; разбор портфеля; симулятор накоплений; 12 инструментов агента |
| `src/skills/` | сценарии: `dcf` (рублёвый WACC), `portfolio-review`, `bond-ladder` |
| `src/agent/agent.ts` | цикл агента с доработками под GigaChat: до 20 шагов, последний — ответ по собранным данным; повтор при обрыве ответа; обязательный `draft_order`, если просили сделку; текст, написанный вместе с вызовом инструмента, не теряется |
| `src/agent/number-check.ts` | сверка чисел ответа с данными |
| `src/web/` | HTTP-сервер: SSE с шагами агента, лимиты, сессии, статика |
| `web/public/` | интерфейс сайта, без сборки |
| `src/tools/fetch/egress-guard.ts` | запрет запросов `web_fetch` в локальную сеть и на localhost |

## Инженерные решения

- **Модель.** По умолчанию GigaChat через собственный адаптер. Готовый пакет `langchain-gigachat` отдаёт пустые схемы инструментов на zod v4, поэтому написан свой. Поддерживаются также модели OpenAI, Anthropic, Google и Ollama.
- **Данные.** 12 инструментов по российскому рынку. Мета-инструменты с внутренним вызовом модели заменены прямыми — вдвое меньше обращений к LLM.
- **Пользовательские задачи.** Разбор портфеля, план накоплений и черновик заявки — законченные задачи, а не только исследование компаний.
- **Промпты.** Системный промпт, профиль канала и `SOUL.md` написаны на русском с учётом рынка: высокая безрисковая ставка, дивиденды госкомпаний, налоги, раскрытие отчётности.
- **Навыки.** DCF под рубли, разбор портфеля, лестница ОФЗ.
- **Цикл агента.** GigaChat вызывает один инструмент за ход, поэтому шагов до 20, а инструменты отчётности, дивидендов и заявок принимают сразу несколько бумаг: сравнение четырёх банков с заявками укладывается в 4 хода. Если шаги кончились, агент отвечает по собранным данным, а не сообщением об ошибке.
- **Сайт.** Веб-канал с потоковой лентой шагов, источниками, графиком цены и значком сверки чисел. На сайте доступны только инструменты данных: без файлов, shell, браузера и памяти.
- **Безопасность публичного стенда.** Лимиты на сессию, день и параллельные запуски; запрет запросов во внутреннюю сеть; очистка HTML ответа (DOMPurify) и строгий CSP.

## Ограничения

- Котировки задерживаются на 15 минут; для реального времени нужен T-Invest API или платная подписка MOEX.
- smart-lab — сторонний агрегатор: данные стоит перепроверять по отчётности компании; у части эмитентов раскрытие сокращено.
- Ожидаемая дивдоходность — по последней отчётности и прошлым выплатам, а не прогноз.
- Симулятор накоплений опирается на историю MCFTR за 10 лет и текущую кривую ОФЗ; это сценарии, а не обещание доходности.
- Шлюз WhatsApp и долговременная память пока не адаптированы под рынок и на сайте выключены.
