# Лестница облигаций

## 1. Вводные

Сумма, срок и цель (накопить к дате или получать регулярный доход). Если чего-то нет — возьми срок 3 года и цель «накопить», укажи это в ответе.

## 2. Данные

Параллельно:

- `get_macro` с `["key_rate", "yield_curve", "inflation"]`;
- `get_bonds` с `kind: "ofz"`, `fixed_coupon_only: true`, `max_years` = срок + 0.5, `sort_by: "maturity"`, `limit: 30`.

Если пользователь готов к риску выше госбумаг, добавь `get_bonds` с `kind: "corporate"` и `max_yield` не выше доходности ОФЗ + 5 п.п. (бумаги с доходностью сильно выше — признак риска дефолта, прямо предупреди об этом).

## 3. Построение

- Раздели сумму на 3–5 «ступеней» с погашениями, равномерно распределёнными до конца срока.
- Для каждой ступени выбери одну бумагу с фиксированным купоном и заметным оборотом (`valueTodayRub`).
- Считай стоимость одной облигации: цена (% от номинала) × номинал / 100 + НКД. Количество — целое число.

## 4. Результат

1. Таблица: бумага, погашение, доходность к погашению, количество, сумма.
2. Средневзвешенная доходность лестницы против ключевой ставки и инфляции.
3. Ближайшие купонные даты (через `get_bonds` с `secid` для 1–2 бумаг).
4. Налог: купоны облагаются НДФЛ 13% (15% с дохода свыше 2,4 млн ₽ в год).
5. Риски: при снижении ключевой ставки реинвестировать купоны придётся под меньшую доходность; при продаже до погашения цена может быть ниже покупки.
6. Черновики заявок через `draft_order` для каждой ступени, если пользователь назвал сумму.
